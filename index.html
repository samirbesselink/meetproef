Meetproef: PlayCanvas tegen Godot

  1. Chromebook aan de lader, alle andere tabbladen dicht.
  2. Open de zes meetlinks van boven naar beneden. Elke link opent een nieuw tabblad: sluit het vorige.
  3. Raak 30 seconden niets aan. Druk dan op Kopieer en plak in één notitie.
  4. Speel daarna één keer zelf en noteer het model van het Chromebook (sticker onderop).
  5. Stuur de notitie naar Claude.

Meten, ronde A

  1. PlayCanvas, run 1
  2. Godot, run 1
  3. Godot, run 2

Meten, ronde B

  1. PlayCanvas, run 2
  2. PlayCanvas, run 3
  3. Godot, run 3

Zelf spelen

Pijltjes of WASD, spatie = springen. Loop van de start naar het gele vak.
